# Privacy

Smart Image Paste processes images entirely inside Chrome. It does not operate a server, transmit images to its developer, collect analytics, or sell data.

The active PNG is stored in the extension's local IndexedDB until it is replaced, cleared, or the extension is removed. Settings and image metadata are stored in Chrome local extension storage. When the user attaches an image, the destination website receives the PNG as though it had been selected from a file input; that website's own privacy policy then applies.

Website access is optional. The popup lets you grant access to the current site or to all HTTP and HTTPS websites. You can remove those grants using the corresponding popup control or Chrome's extension settings.
